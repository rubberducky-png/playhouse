# playhouse

this was created for the Playhouse program by hackclub, a CAD YSWS to design a 14x14cm room and fill it with furniture.
I decided to create my brothers and I's old room and gift it to my older brother as he is out of college and probably moving somewhere
My room has:
- bunk bed
- beanbag (public model from https://cad.onshape.com/documents/715e9507b1d83332e93e9f8e/w/269e7dd8f90988f72008b7e0/e/af8aace7ae977653f308e9af)
- two dressers
- shelves,
- pullout bed
- bank
- books
- windows
- ceiling fan
- trophy
- storage boxes

shout out the hackclub people that put this program together
